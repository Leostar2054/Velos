## Code and data of the Client

* `backend/velos_recon/core.py` — the Client's ptychography engines (`ptycho_core.py`), vendored unchanged.
* `backend/velos_recon/fpm.py` — Python port of the Client's MATLAB FPM quick-check engine.
* `examples/fpm/*.npz` — crops of the Client's own LED-array FPM acquisitions (blood smear, leaf section).
* The 635 nm clam / 675 nm plant example datasets used in M2–M3 come from a published academic package (non-commercial use); they are used for development and testing only and are not redistributed in this repository.

## Trained models

`models/velos-refine-v2` and `models/velos-refine-fpm-v1` were trained for Velos BioImaging on simulated data and the Client's data; see each `model_card.json` (owner, training data, intended use, limitations).
